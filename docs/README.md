# HappyAccess docs

These pages cover HappyAccess 1.1. Start with the first one if you're new, or jump to the one you need.

- [Getting started](getting-started.md): install HappyAccess, find it under Users, and turn on the features you want.
- [Temporary access](temporary-access.md): give a support person a login link or code that ends by itself.
- [Passwordless login](passwordless-login.md): let people log in with a code or link sent to their email.
- [Two-step login](two-step-login.md): ask for an app code, an email code or a backup code after the password.
- [Locked out](locked-out.md): every way back in, step by step.
- [Developers](developers.md): WP-CLI commands, hooks, wp-config constants and multisite.
- [Privacy and security](privacy-and-security.md): what HappyAccess stores, its cookies, and how codes are protected.

Found a security issue? Please report it privately through the [security policy](../SECURITY.md), not in a public issue or the support forum.
